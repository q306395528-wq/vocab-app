# 墨记单词 · 网页版背单词 App

一个类似「墨墨背单词」的英语单词学习应用，基于**间隔重复（遗忘曲线）算法**，纯前端、无需联网、进度自动保存在浏览器本地。

## 功能
- **首页**：今日待学（复习 + 新词）、每日目标进度、掌握概览、连续打卡。
- **学习**：翻卡式记忆，显示音标 / 释义 / 例句，点 🔊 可发音；三档反馈「忘记 / 模糊 / 认识」，按钮上实时显示下次复习间隔。
- **统计**：近 14 天学习量柱状图、掌握率、各状态占比。
- **词库**：调整每日新词量、导入自定义单词（`单词,释义,例句`）、查看全部单词状态、清空数据。
- 内置 138 个常用词（CET4/CET6/GRE），可无限扩充。

## 运行方式
方式一：直接双击 `index.html` 用浏览器打开即可。

方式二（推荐，避免个别浏览器限制）：在本目录下起一个本地服务器
```bash
python3 -m http.server 8777
```
然后浏览器访问 http://localhost:8777

## 记忆算法：基于遗忘曲线的记忆模型（FSRS / DSR 思路）
不再用简单的固定倍数，而是给每个单词维护三个记忆量：
- **稳定度 Stability (S)**：保持力，越大越久才忘（≈天）。
- **难度 Difficulty (D)**：1~10，越难间隔涨得越慢；老记不住的词 D 会升高，简单的词 D 降低——**每个词自适应**。
- **可提取度 Retrievability (R)**：距上次复习 t 天后还记得的概率，遵循幂函数遗忘曲线
  `R(t) = (1 + FACTOR·t/S)^DECAY`，下次复习安排在 R 降到目标保持率（默认 90%）的时刻。

核心规律：
- **在快要忘记时复习（R 低）→ 稳定度提升最大**（间隔效应，符合真实记忆规律）；
- **认识** → S 增长、间隔拉长（间隔 ≥ 21 天自动「已掌握」），移出今日队列；
- **模糊** → S 小幅增长（约为认识的一半）、难度略升，今天稍后（约 9 张卡后）再出现；
- **忘记** → S 大幅回落、难度上升、重新学习，今天稍后（约 5 张卡后）再出现。

只有点「认识」才算本轮通过；模糊/忘记的词会被**错开若干张卡**后再循环，不会紧接着又冒出来。

一路「认识」的间隔示例：3 → 8 → 20 → 45 → 95 → 189 → 356 → 638 天。
按钮间隔提示：认识「X 天后」；模糊 / 忘记「今日 / X 天后」。

> 说明：这是学术界成熟的**间隔重复记忆模型**（FSRS 的简化实现），依据遗忘曲线动态调度，
> 并按每个词的难度做个性化，而非字面意义上的神经网络「深度学习」。

## 数据存储
所有进度保存在浏览器 `localStorage`（键 `momo_vocab_v1`），换浏览器或清缓存会丢失。
